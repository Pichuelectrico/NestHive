# NestLink — Prototipo Visual del Dashboard

## Cómo abrirlo
```bash
cd /Users/joshuareinoso/Downloads/Hackathon_InnoLabs_MVP_Plan/prototype
python3 -m http.server 8080
```
Abre http://localhost:8080 en el navegador. También funciona con `file://` directo sobre `index.html`.

## Qué muestra
Dashboard simulado en vivo: mapa 2D blueprint con 4 AMRs Nestlé animados, peatones con radio de seguridad, bloqueos dinámicos en pasillos, kanban de misiones priorizadas, gauges de material por línea y KPIs de ROI.
